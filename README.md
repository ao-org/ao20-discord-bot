# ao20-discord-bot

Official bot for Argentum 20 discord server.

## Publicación de noticias

Usá `/publicartexto` con la opción `texto` para publicar en el canal
`1570162557203906600`. Solo integrantes con el rol `Staff` pueden usarlo; las
menciones dentro del texto no generan notificaciones.

Dale al bot permiso para ver el canal de noticias y enviar mensajes. El comando se
registra en el servidor configurado al iniciar el bot.
